# Blog Conformo

Articles publiés sur https://conformiteue.com/blog par l'agent « Stratège SEO » du Studio Conformo.

- `articles/index.json` : liste des articles (le plus récent en premier).
- `articles/<slug>.json` : un article (titre, description, corps HTML, FAQ, sources).

Le site lit ces fichiers en direct (cache de 5 minutes) : aucun redéploiement n'est nécessaire.
Pour retirer un article : supprimer sa ligne dans `index.json` et son fichier.
